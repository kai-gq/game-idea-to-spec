# Game Idea To Spec

一句话游戏想法 → GameForge 可直接粘贴的标准游戏规格。

## 这是什么

把「帮我做个射击 / 卡牌 / 益智 / 弱视训练小游戏」这类一句话需求，通过几步选择题引导，整理成 GameForge 输入框可直接粘贴的标准三段式规格（**游戏名称 / 游戏玩法 / 美术风格**）。

## 功能特性

- 支持**普通休闲小游戏**（射击 / 卡牌 / 塔防 / 跳跃 / 益智等）与**弱视 / 双眼视训练小游戏**（精细 / 同视 / 融合 / 立体）
- 全程选择题交互，用户只需点选，零门槛、不填表
- 玩法细节按所选方案**动态生成**，输出 400~700 字详细玩法（含操作 / 胜负条件 / 敌人行为 / 难度递进 / 得分反馈）
- 最终输出可直接粘贴进 GameForge 输入框（游戏名称 / 游戏玩法 / 美术风格 三格）

## 使用流程

1. 用户说出游戏想法（如「帮我做个射击小游戏」）；
2. 依次完成 4 步选择题：
   - **训练类型**：普通 / 精细训练 / 同视训练 / 融合训练（立体训练可打字指定）；
   - **游戏方案或配色**：普通类 → 同类 5 个玩法方案选 1；训练类 → 红蓝 / 红青配色 2 选 1；
   - **玩法细节**：按所选方案动态生成 3~4 个相关问题（目标 / 难度 / Boss / 操作等）；
   - **美术风格**：4 选 1（普通类默认扁平卡通，训练类默认训练简洁）。
3. 输出三段式规格，复制进 GameForge 输入框，点「开始生成」。

## 输出格式

三个独立字段，逐框复制：

| 字段 | 说明 |
|---|---|
| 游戏名称 | 2~8 字，贴合玩法与受众 |
| 游戏玩法 | 400~700 字详细玩法，一段讲完 |
| 美术风格 | 1~2 句风格短语 |

## 环境要求

- 豆包桌面版（依赖 `interaction.ask` 交互式选择题组件）
- GameForge（接收三字段规格的游戏生成引擎）
