# 方案素材库：类型池、玩法骨架、风格池、特效等级池

供常规流程（出方案、玩法确认、选风格、选特效等级）与弱视流程（训练类型、出方案、问法库）取用。
**类型必须落在本项目能做出来的范围内**
（对应 web-game-dev 的 genres：平台跳跃 / 动作射击弹幕 / 俯视角 RPG / 卡牌回合 / 塔防生存 /
以及已实测的横版跑动射击；用户自报类型走"其他"行判断）。
超范围的类型（3D、开放世界、联网对战）不给出。

## 类型池（每个 = 类型名 + 一句话玩法骨架）

| 类型 | 玩法骨架（怎么玩） | 难度档 |
|---|---|---|
| 横版跳跃 | 左右移动+跳跃，踩敌人头顶消灭，碰到敌人掉血，收集金币，冲最高分 | 易 |
| 横版跑动射击 | 边跑边自动/手动开火，向前清怪，躲障碍，打 Boss 通关 | 中 |
| 弹幕射击 | 飞船左右移动躲避弹幕，自动开火清怪，分数/关卡递进 | 中 |
| 塔防生存 | 在路径旁造塔，挡住一波波怪物，守到最后一波或无尽刷分 | 中 |
| 俯视角 RPG | 地图上走位，靠近怪物攻击，打怪升级学技能，探索地图 | 中高 |
| 卡牌回合 | 抽牌出牌打怪物，费用管理，回合制，牌组越打越强 | 中 |
| 消除益智 | 点两个相邻块交换，三个同色消除得分，限步数/限时 | 易 |
| 接物收集 | 移动角色接住下落的物品得分，躲开坏物，无尽刷分 | 易 |
| **其他** | 用户自报的类型：先判断能不能做成 2D Web 小游戏（能→采纳并补一句话玩法骨架；3D/联网/超大体量→告知做不了，给最近似替代） | 视情况 |

## 弱视训练池（弱视分支专用）

### 训练类型（4 类，每类 = 训练目的 + 一句话玩法骨架）

| 训练类型 | 练什么 | 玩法骨架（怎么玩） | 难度档 |
|---|---|---|---|
| 精细训练 | 分辨细小差异 | 找出两个相似图形里的细微差别 / 数字字母大小区分 / 连线走迷宫 | 易~中 |
| 同视训练 | 双眼同时感知、互不抑制 | 左眼看图形 A、右眼看图形 B（点数/图案不同），分别说出两眼看到的内容 | 易~中 |
| 融合训练 | 双眼互补拼合 | 左眼看图形左半、右眼看右半，融合成完整图形后识别（数字/动物/形状） | 中 |
| 立体训练 | 视差融合出深度 | 多个图形视差浮出，找出浮得最高/最深的那个；或单图看出前后层次 | 易~中 |

### 弱视素材池（第 3 轮出方案取用）

骰子（点数 1-6）｜圆形/三角形/方形｜数字 0-9｜动物剪影（猫/鱼/鸟）｜星星/月亮｜字母。
规则：图形**大而简洁、对比强烈、深色背景**；同一训练类型内素材之间可混搭换题。

### 弱视玩法问法库（第 4 轮取用）

按所选训练类型挑 2 个问题给选项（3~5 个）：

- **题目形式**：点击选择 / 口头回答（说数字）/ 限时挑战 / 连续闯关
- **难度档**：入门（图形大、点数 1-3、视差明显）/ 常规 / 进阶（图形小、点数 1-6、视差精细）
- **题量节奏**：5 题一局 / 10 题一局 / 无尽连续
- **反馈方式**：对错提示音 / 星星得分 / 闯关进度条
- **目标对象**：练左眼 / 练右眼 / 双眼都要练

## 玩法细节问法库（第 3 轮取用）

按类型挑 2 个问题给选项，选项 3~5 个：

- **目标**：无尽刷分 / 限时冲分 / 打到第 N 关 / 打败最终 Boss
- **操作**：一根手指就能玩 / 方向+一个动作键 / 方向+攻击+跳跃
- **难度曲线**：全程很轻松 / 慢慢变难 / 前面简单后面刺激
- **收集养成**：只收集金币 / 收集+升级 / 收集+解锁新角色
- **失败惩罚**：碰到就掉血（3 条命）/ 碰到掉血但能回血 / 一碰就结束

## 风格池（第 4 轮取用）

| 风格 | 一句话描述 | 适合类型 | 备注 |
|---|---|---|---|
| 扁平卡通 | 鲜艳大色块、厚描边、无阴影 | 全部 | **最稳默认**，AI 出图一致性好 |
| 像素风 | 8-bit 怀旧小方块 | 动作/射击/RPG | 复古感强 |
| 手绘蜡笔 | 儿童绘本感、柔和线条 | 跳跃/益智 | 很"儿童" |
| 卡通低多边形 | 色块拼贴、几何感 | 塔防/RPG | 现代感 |
| 科幻霓虹 | 深底亮色、发光线条 | 弹幕/射击 | 酷但难出图 |
| 水墨国风 | 黑白淡彩、写意 | RPG/塔防 | 风格独特、AI 出图风险高 |
| 训练简洁 | 深色背景、纯色图形、高对比、无装饰无渐变 | 弱视训练专用 | **弱视默认**，不用风格池选项 |

**选择规则**：用户说"随便"时选扁平卡通（最稳）；弱视训练一律选「训练简洁」；
用户要"酷/帅"选像素或霓虹；用户给小孩玩选扁平卡通或手绘蜡笔。

## 特效等级池（第 5 步取用：问完美术风格后问特效等级）

| 等级 | 定位 | 包含特效（写进玩法） | 实现要点 |
|---|---|---|---|
| 普通 | 基础必要反馈，轻快简洁 | 得分飘字、命中/得分音效、受伤简单闪烁、按钮点击反馈 | 最少粒子，动画 0.1s 内，优先性能不卡顿 |
| 中等（默认推荐） | 手感级核心特效，性价比最高 | 受击反馈（闪白/抖动/击退）、死亡碎裂或消散、子弹爆炸小粒子、消除特效（同色缩放+碎片飞出+飘字）、连击飘分 | 粒子数量适中，动画 0.1~0.3s，每个事件配音效 |
| 高级 | 电影感细致特效，画面最炫 | 在中等基础上加：多层粒子（火花+烟雾+碎片）、命中停顿 hit-stop、屏幕震动、慢动作特写、弹道拖尾、连击光效、镜头缓动 | 粒子分层叠加，动画 0.3~0.8s，多音效层 |

**选择规则**：默认推荐**中等**（覆盖受击/死亡/爆炸/消除这类核心反馈，性价比最高）；
用户要"轻快不花哨/别太闹"选**普通**；用户要"炫/震撼/画面好看"选**高级**。

## 出方案纪律

- 类型不重复：5 个方案必须有 ≥4 个不同类型；
- 紧跟原话：用户提到的元素（龙/太空/农场…）必须在某个方案里显式出现；
- 1 个方案带"新鲜感"：在常见类型上加一个用户没说的有趣点
  （例：横版跳跃 + "怪物会变大"）；
- 全部可做：不出 3D / 联网 / 超大体量类型。
